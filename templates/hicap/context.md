# Hicap workspace context

Use this workspace to identify companies that may need a shared control layer
for AI usage across teams, models, budgets, access policies, audit trails, and
cost attribution.

The network graph is assembled from teammate-provided LinkedIn exports or an
optional live provider configured by the workspace administrator. Always retain
which teammate owns a relationship. A warm path is a routing signal, not proof
of willingness to make an introduction.

Recommended agent behavior:

1. Import or refresh the target company list.
2. Import each teammate's own LinkedIn connection export with an owner name.
3. Match people to companies using the shared ICP.
4. Explain the evidence and relationship owner for every suggested path.
5. Keep unknown evidence explicit and ask for research rather than inventing it.
